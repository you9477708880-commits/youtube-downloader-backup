# 候選版一次性人工驗收（2026-08-29）

用途：確認自動測試無法替代的文字理解、資訊量與真實操作感受。自動化已涵蓋帳務規則、資料隔離、同步衝突、450 筆 CSV 帳戶修復、Emulators 20/20 與 UI smoke 15/15；這裡不要求重新製造危險的雲端衝突。

預估時間：5–10 分鐘。

## 開始前

1. 請 Codex 在 `codex/next` 執行 `npm run preview:acceptance`。
2. 開啟 `http://127.0.0.1:4186`，確認頁首顯示「本機驗收版」與「驗收版｜僅本機」，Google 登入不可用。
3. 若要使用真實資料，只匯入從正式站匯出的 JSON 副本。驗收包使用獨立 localStorage／IndexedDB，不連 Firebase。
4. 不要在這次驗收中測正式帳號刪除、正式雲端覆蓋或真正部署。

## 這次只需複驗的四個修正

其他候選功能已由使用者標記通過，不需要重新走完整清單。以下四項是本輪人工回報後的收斂修正。

### 1. 總覽與月度回顧

- 選一個有交易的月份，確認收入、生活支出、準備金動用與可自由運用可對回資料。
- 展開「與上期比較」，確認月度回顧仍可正常使用。
- 確認獨立「財務導航」與無法記錄答案的自評問題已移除，頁面沒有留下空白卡片或異常間距。

### 2. 記帳搜尋與週期間隔

- 搜尋「洗牙」「汽車」或「保養」，切換近 6 個月／全部時間；確認提示明示搜尋期間不影響月度報表。
- 點開一筆長備註交易，確認詳細卡片可完整閱讀，也可直接修改備註、交易類型與帳戶。
- 展開「檢查這個搜尋的週期間隔（選填）」並輸入間隔；確認它直接沿用上方同一個搜尋關鍵字，只補充最近日期、平均間隔與預計日期，不再出現第二個關鍵字欄位或重複的最近交易清單。

### 3. 對帳調整刪除

- 在驗收資料建立一筆對帳調整，從交易清單點開其明細。
- 按紅色「刪除這筆帳戶調整」，確認訊息說明帳戶餘額會重新計算；刪除後明細關閉且餘額回到調整前。

### 4. 退休配置漂移與再平衡

- 展開「護欄年度檢查」，確認欄位清楚寫「上年度期初配置比例」，期初與目標配置需各合計 100%。
- 設期初與目標都是股票 60%、債券 30%、現金 10%，債券報酬 0%；把股票報酬先設 10% 再設 20%，確認推估的目前股票比重與超配金額會改變，且來源先顯示賣出超配股票，而不是固定只領現金。
- 將股票報酬設為負值，確認來源順序仍保護下跌股票並優先顯示現金／債券；緊急預備金只有明確勾選後才可使用。
- 重新載入後，護欄輸入不保存，也不會建立交易。

## 通過後的發布順序

人工驗收通過後才執行：合併到 `main` → 推送 GitHub → 等 CI 通過 → `npm run deploy:hosting:production` → 正式站唯讀檢查。Firestore Rules 沒有變更；Firebase Functions 不部署。
