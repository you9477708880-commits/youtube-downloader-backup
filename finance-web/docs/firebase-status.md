# Firebase 狀態文字規格

這份文件定義前端同步狀態的使用者文字。目標是讓使用者知道「資料是否安全」與「是否需要操作」，不要把 Firebase 技術錯誤直接暴露在畫面上。

## 顯示原則

- 對使用者說結果，不說內部錯誤。
- 狀態文字要短，詳細技術訊息放在 `console.warn()` 或開發文件。
- 正常登出不應顯示錯誤。
- 初次載入、尚未登入時，不應顯示同步異常。
- 離線時要告訴使用者資料會先保存在本機。

## 建議狀態

### 僅本機

顯示：

```text
💾 僅本機
```

說明：

```text
目前資料只存在這台裝置。
```

適用情境：

- Firebase 尚未設定。
- 使用者尚未登入。
- 使用者選擇登出後回到本機使用。

### 已登入，準備同步

顯示：

```text
☁️ 準備同步
```

說明：

```text
已登入 Google，正在確認雲端資料。
```

適用情境：

- Google 登入成功後。
- Firestore 第一次讀取前。
- 等待雲端資料合併時。

### 雲端同步完成

顯示：

```text
☁️ 雲端同步
```

說明：

```text
資料已同步到你的 Google 帳號。
```

適用情境：

- Firestore 讀取成功。
- Firestore 寫入成功。
- 本機與雲端狀態已確認。

### 暫時離線

顯示：

```text
📴 暫時離線
```

說明：

```text
目前無法連到雲端，資料會先保存在本機。
```

適用情境：

- 網路中斷。
- Firestore 暫時無法連線。
- Firebase SDK 回報離線或快取狀態。

## 不建議直接顯示的文字

以下文字容易讓使用者誤以為資料壞掉，建議只放在開發者 console 或錯誤紀錄：

- Firebase 未啟用。
- 同步異常。
- 登入流程失敗。
- 權限錯誤。
- 快取中。
- 尚未切回匿名模式。

## 使用者行動提示

只有在使用者真的需要行動時，才顯示明確提示：

- 需要重新登入。
- 網路恢復後會自動同步。
- 無權限存取這份資料。

## 維護檢查點

修改登入、登出或同步流程時，請確認：

- 正常登出不顯示警告。
- 初始本機模式不顯示同步異常。
- 成功登入後能顯示帳戶名稱或 email。
- 寫入成功後顯示雲端同步。
- 離線時文字是安撫型，而不是錯誤型。
